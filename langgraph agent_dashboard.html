RAG Pipeline vs Agent — 핵심 차이

🔬 이전 RAG 파이프라인과 무엇이 달라졌나

RAG Pipeline (이전)
LLM 1회 호출 후 종료.
도구 호출이 발생해도 결과를 LLM이 다시 받지 않음.
공격 = 단일 도구 1개 실행.

→ 공격 범위: 이메일 1통, 권한 1개
LangGraph Agent (지금)
LLM이 루프로 반복 호출됨.
도구 결과를 보고 다음 행동을 스스로 결정.
S4처럼 rag→email 연쇄가 가능해짐.

→ 공격 범위: 루프 내 무제한 연쇄 가능
NeMo 방어 차이
RAG: 시스템 프롬프트가 도구 호출 키워드 억제.
Agent: Planner 노드 진입 시점에서 거부.
→ ToolNode, Observer 노드 자체를 거치지 않음.
루프 차단 = 연쇄 공격 원천 봉쇄
